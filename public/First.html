Your models

Activate a GGUF to load it in-process when node-llama-cpp is installed, otherwise AngChat starts llama-server if it is on PATH. You can also point Settings at Ollama or another OpenAI-compatible server. Removing a model only removes it from this list; files are retained.

Local inference runtime

Checking the server configuration…

AngChat can load GGUF files inside the Node process with optional node-llama-cpp, spawn llama-server, or talk to Ollama. Install a llama.cpp build from the official releases if you want the server path. Set LLAMA_SERVER_PATH in backend/.env when the binary is not on PATH. Hugging Face Transformers folders still need conversion to GGUF or an external runtime.

Settings

Provider settings are held by the backend process. API keys are never returned by the settings endpoint.

Provider connection

Use in-process GGUF inference, Ollama, a hosted API, a local OpenAI-compatible endpoint, or Mock mode. Mock mode deliberately does not call a model.

Ollama defaults to http://127.0.0.1:11434. Local llama-server URLs should end in /v1. In-process inference ignores the URL.
