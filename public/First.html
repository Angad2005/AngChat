Add a model to AngChat, then activate it for the harness. Model files stay in your local models/ folder unless you import a folder from another path.

Enter a repository and choose one GGUF file. Gated repositories may require a read token; it is used for this request only.

Add a model from this computer

Checking the server configuration…

Install a llama.cpp build for your machine from the official releases. AngChat finds llama-server on PATH, or you can set LLAMA_SERVER_PATH in backend/.env and restart. You can also run another compatible server and set its OpenAI-compatible /v1 URL in Settings. GGUF activation starts a real local server only when one is available.
